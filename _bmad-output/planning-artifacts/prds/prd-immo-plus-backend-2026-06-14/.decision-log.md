## D-A3 — FR-47 : @Roles explicite sur tous les endpoints mutants (2026-06-14)

**Décision**: `DELETE /agencies/:id/members/:memberId` → `Role.OWNER | Role.ADMIN`. Règle générale : tout `@Delete/@Post/@Patch/@Put` porte `@Roles(...)` ou `@Public()`.

**Justification**: Le guard global `JwtAuthGuard` vérifie l'authentification, pas l'autorisation. Sans `@Roles`, tout utilisateur authentifié — y compris TENANT — peut invoquer l'endpoint. Audit C2.

## D-A5 — FR-55 : TVA configurable, snapshot préservé, A-7 du PRD parent fermée (2026-06-14)

**Décision**: Le taux de TVA passe de hardcode à `AdminSettings.tvaRate` (défaut 19,25 %). Comportement snapshot maintenu sur `Commission.tvaRate`. La modification du taux ne recalcule pas les commissions existantes (A-B2 en attente OQ-A1).

## D-A9 — OQ-A1 résolu : TVA rétroactive sur PENDING (2026-06-14)

**Décision**: La modification du taux de TVA dans AdminSettings recalcule immédiatement toutes les commissions dont le statut est `PENDING` (`tvaRate`, `tvaAmount`, `amountTTC` mis à jour). Les commissions `PAID` et `CANCELLED` ne sont jamais modifiées. FR-55.4 mis à jour en conséquence.

**Justification**: Une commission PENDING n'a pas encore été encaissée. Appliquer le nouveau taux réglementaire aux commissions non payées est la seule position légalement correcte.

## D-A10 — OQ-A2 résolu : Cloudflare Turnstile retenu (décision experte) (2026-06-14)

**Décision**: Cloudflare Turnstile est retenu comme solution anti-bot pour FR-49 (endpoints publics `/applications`). Throttler IP 5/heure maintenu en défense en profondeur.

**Justification**: (1) Même vendor que Cloudflare R2 déjà en stack — simplicité opérationnelle. (2) Mode invisible (challenge silencieux) — zero friction utilisateur, critique dans un marché à connectivité variable. (3) Privacy-first, pas de fingerprinting Google. (4) L'approche throttler seul est insuffisante — les bots rotatent les IPs. (5) reCAPTCHA v3 rejeté : dépendance Google, données de navigation collectées.

**Variables d'environnement requises**: `TURNSTILE_SECRET_KEY`, `TURNSTILE_SITE_KEY`.
